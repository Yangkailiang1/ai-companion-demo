## 依赖拓扑图

```
T2 语义世界 ───────┬──> S3 物体状态
                   ├──> C4 角色场景交互
                   └──> D2 剧情走位

C1 动作路由 ───────┬──> C2 动作库
                   ├──> C3 表情
                   └──> D2 导演表现

S2 多地点 + X1 存档 ──> C5 日程/离屏模拟 ──> 小镇居民生活

C6 角色导入 + T3 插件接口 + O4 安全 ──> 对外开放角色包

P2 玩家控制 + P3 交互 + C4 接触系统 ──> 玩家与角色共同活动

D1 剧本格式 + C5 多 Agent + S2 多地点 ──> D2 完整剧情导演

T3 插件接口 + X1 迁移 + X2 测试 ──> O1 开源 Runtime
```
