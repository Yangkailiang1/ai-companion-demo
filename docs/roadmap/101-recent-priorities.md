- `[DONE S3 reuse]` 厨房新增真实 `RigidBody3D` 餐桌饮料，可拿起、放下和投掷。
- `[DONE S2 expansion]` seed 303 独立参数化书房接入住宅地点图，复用统一家具
  Registry，并带可拿取/投掷的刚体书本。
- `[DONE S2/C5/X1]` 持久居民归属注册表、角色独立 `traverse`、按房实体化与
  Schema v2 可选归属存档完成；AI 过门不再切换玩家房间。
- `[DONE S2.5/P2]` 五个住宅房间按世界原点拼接，几何/碰撞常驻、当前房间导航
  激活；玩家身体穿门不传送、不白屏、不坠落，语义房间随身体更新。
- `[DONE S1.1]` 对话记录默认折叠并缩小展开面积，输入区继续保持可见。
- `[DONE S3.6a/C9.5a]` 新增可踢靠枕和动态物体位移感知；最近空闲角色会形成
  记忆并执行看、说、走、拿、放的整理反应。
- `[DONE S2.2]` 房门升级为带碰撞的动态门扇：接近开门、跨门槛切房、到达侧
  保持开启并自动关闭；成对门只启用当前侧碰撞。
- `[DONE C5.6/S5]` 离屏居民会低频推进需求、地点、记忆和活动结果；进入房间
  可看到最近生活痕迹，日志进入存档且演出模式暂停。
- `[DONE S1.2]` 五房间改为 Manifest 驱动的独立三灯光组，仅活动房间启用；
  压低环境曝光并加入 SSAO 与柔和阴影，避免多房方向光叠加和浅色角色过曝。
- `[DONE C4.4/C9.5b baseline]` 新增可携带浇水壶，浇水链已包含取壶、携带、
  植物反馈和放下，并有真实动作队列合同测试。
- `[DONE C8.3/S1.2]` 企鹅、诀及三名动态 Q 版角色统一接入二次元 Toon
  光照与透明贴图感知描边；线宽按模型缩放校正，房间家具继续保持 PBR。
- `[DONE D2.2/C8.3/S1.2]` 剧情 Beat 自动生成单人/双主体镜头，平滑切入和
  恢复观察构图；演出姓名牌自动隐藏，角色加入 Rim Light 与暖色面部补光，
  第一人称模式保持玩家控制。
- `[DONE D2.3/C7.2]` 镜头语法覆盖走位远景、双人中景、对白特写、物体交互与
  动作中景；机位使用物理射线候选规避遮挡，启用 ECNU TTS 时按文本和语速估算
  最低对白停留时间；演出结束使用安全碰撞恢复，最终站位不再被拥挤居民推出。
- `[DONE S2.2/S3/S4.3 v0.8.14]` seed 404 阳台绿植房以可复现 Recipe 接入书房，
  新增真实窗洞、独立暖光、两盆有含水状态的植物、可开关落地灯、可拿取水壶/
  饮料和动态靠枕；五房门洞、导航、物理、语义和 Metal 画面通过验收。
- `[DONE S4.1 v0.8.14]` Recipe/Manifest 新增逐实例 `scale` 与可编译 lighting，
  布局约束、碰撞和模型尺寸使用同一倍率，房间不再需要编译后手改灯光数据。
- `[DONE T2.2/C9.1 v0.8.14]` GOAP/Utility 蓝图中的 `plant/sofa/watering_can`
  功能引用会按当前房间 affordance 解析；角色在阳台可自动选择主植物、水壶和
  扶手椅，旧生活脚本不再被客厅语义 ID 锁死。
- `[DONE C4.4/C9.5b/S3.1 v0.8.15]` 可携带工具新增通用 `play_tool_use`
  表现协议；角色浇水时水壶会倾倒、壶嘴产生水滴粒子和程序化水声，结束后恢复
  持有姿态。真实五步动作队列、植物状态和 Metal 画面均已验收。
- `[NEXT]` 补浇水手部 IK、身体/壶嘴精确对齐与水量失败反馈，并完成双角色共同看电视；地点扩展后升级为当前房间 +
  相邻一跳流送。
