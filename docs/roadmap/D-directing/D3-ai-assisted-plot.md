## 规划方向

### 自然语言转剧本

- `[DONE MVP]` LLM 把自然语言剧本转为受约束 Story JSON
- `[DONE MVP]` 注入角色人设、独立记忆、模型动作、物体 affordance 和安全路点
- `[DONE MVP]` 本地白名单校验，失败自动反馈修复一次
- `[DONE live]` ECNU `ecnu-max` 真实完成电视邀约和浇水/读书两类动态演出
- `[DONE live cast]` 从玩家文本中解析所有被点名的注册角色；ECNU 已一次生成并
  执行五角色、16 Beat 的“小尬剧”，覆盖走位、物体交互、动作、对白和独立记忆
- `[DONE baseline]` 空可选字段规范化、60 秒窗口和一次受限传输重试

### 即兴槽位

- 只允许在导演定义的"即兴槽位"中扩写对白
- 角色人设、关系和已有记忆影响即兴内容

### 质量控制

- `[DONE baseline]` 已保存 Story JSON 可直接重放
- `[NEXT]` 生成结果可预览、编辑、确认和版本化

## 双模式边界

- `[DONE MVP]` 自由模式：自主调度和每角色认知循环持续运行
- `[DONE MVP]` 演出模式：普通输入变为剧本，暂停自主调度并进入 Planner
- `[DONE MVP]` `!自由` 取消未完成规划/演出并恢复自由生活
