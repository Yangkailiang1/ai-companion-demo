# 建议版本切片

> 所属文档：AI Living Town 开发规划树
> 最后更新：2026-07-27 | 当前切片：v0.8.7

版本号表示可交付体验，不表示某个大分支必须全部完成。

## 版本规划总表

| 版本 | 主题 | 主要规划节点 | 可见成果 |
|---|---|---|---|
| `v0.6` | 稳定客厅生活 | `S1.1–S1.3`, `S3.1`, `T1.1`, `X1`, `C4.0`, `C5.0` 基础 | 温馨 UI 完整；盆栽会生长/缺水；角色会主动浇水休息；可保存 |
| `v0.7` | 具身生活感 | `C2.1`, `C3.2`, `C4.1–C4.5`, `C9.1–C9.5`, `C7.1` | 角色连续自主生活；完成真实浇水样板；玩家插话时自然转向和响应 |
| `v0.8` | Q版角色小剧场 | `D1`, `D2` 基础, `D3` MVP, `C4.4`, `S3`, `C6`, `C8`, `C5.1–C5.3` | 自由/演出双模式；LLM 动态编排多角色演出；本地 PMX Q 角色通过许可隔离加载器进入剧情；角色可实际拿取、放下和投掷物品 |
| `v0.9` | 从客厅到住宅 | `S2.1–S2.3`, `P2.1–P2.4`, `P3`, `T2.3` | 客厅/卧室/厨房切换；玩家可第一/第三人称活动 |
| `v1.0` | 开源小镇 Alpha | `S2.4–S2.5`, `C6`, `O1–O4`, `X2–X5` | 街道和公共地点；角色导入向导；插件 SDK 与开源文档 |
| `v1.1+` | 参数化与创作者生态 | `S4`, `D3–D4`, `O5`, `R1–R6` | 自动生成住宅/街区、剧情编辑器和可选社区分享 |

## 版本切片规则

- 每个版本最多选择一个基础设施主任务和两到三个用户可见主任务
- 不要求完整做完一个大分支才进入另一个分支
- 所有选定节点之间不存在未解决的前置依赖
