## 关键原则

- **稳定编号**：每个节点有稳定编号（如 `S3.1`、`C4.2`），Issue、提交说明和版本计划应引用该编号。
- **版本切片**：每个版本是从不同分支选择节点组成的交付集合，不要求完整做完一个大分支再进入另一个。
- **每版本上限**：每个版本最多选择一个基础设施主任务和两到三个用户可见主任务。
- **统一协议**：角色、场景和玩家使用相同的空间、交互、资产导入与存档协议。
- **LLM 边界**：碰撞、导航、物体所有权等确定性逻辑必须由本地 Runtime 执行；LLM 只能给出受约束的目标和计划。
