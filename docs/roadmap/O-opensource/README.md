## 分支概述

O 分支确保 AI Living Town 不仅是一个 Demo，而是一个可以被第三方创作者接入、扩展和贡献的平台。

**核心原则**：
- Runtime 代码与 Demo 资产彻底分层
- 所有导入和 Mod 经过安全检查
- 隐私数据和受限资产不进入公开仓库
