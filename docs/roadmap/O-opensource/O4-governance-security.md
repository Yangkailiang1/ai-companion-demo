## 规划方向

### 许可证管理

- 明确代码许可证和每项资产许可证
- `[DONE baseline]` 不可再分发角色统一进入 `assets/local_characters/`；
  公开检出使用占位外观并通过无本地资产回归。
- `[DONE audit]` 推送前扫描待发布历史中的受限资产、大文件与常见密钥格式。
- `[NEXT]` 项目所有者选择代码许可证；在此之前 README 明确不得假定统一授权。

### 隐私保护

- API Key、语音样本、聊天记录和用户模型默认不提交、不上传

### 安全校验

- 为外部模型、脚本和 Mod 设置大小、格式、路径和内容校验

### 社区规范

- 建立贡献指南、行为准则、Issue 模板和安全漏洞报告流程
