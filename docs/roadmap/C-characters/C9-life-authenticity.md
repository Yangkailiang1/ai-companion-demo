# C9. 角色生活感与行为连续性

> 所属分支：C. AI 角色
> 节点编号：C9
> 状态：`[NEXT]`（整体）/ `[ACTIVE]`（多个子节点已有 baseline）
> 依赖：T1（认知协议）、C4（场景交互）、C5（记忆与日程）、S3（交互物体）
> 最后更新：2026-07-29 | 基线程：v0.8.10

## 问题定义

当前 `盆栽缺水 → 浇水 → 沙发休息` 已形成确定性闭环，但仍容易被感知为"事件触发脚本"，还不是持续生活。生活感优化不得只增加随机台词，而应同时补齐动机、身体接触、过渡行为、个性差异和共同活动。

## 目标架构

```
环境状态 + 身体需求 + 日程 + 关系 + 近期记忆
  -> 感知与可见/可达性过滤
  -> Utility AI 候选活动评分
  -> HTN / GOAP 受约束任务分解
  -> 导航、占用、对齐、IK 与物体交互
  -> 动作、视线、表情、语音与环境反馈
  -> 结果写回世界状态和每角色独立记忆
```

## 规划节点

### C9.1 `[DONE baseline]` Utility AI 生活调度器

已按需求缺口、环境紧迫度、人格偏好、心理状态、日程、距离和冷却计算候选活动分数，并提供选择诊断；后续补社交上下文。

- `[DONE multi-room capability routing v0.8.14]` 活动的焦点、资源和 GOAP 动作
  不再要求客厅固定 ID；当前房间存在能力等价对象时，会解析到真实植物、座椅、
  读物、饮料和水壶。阳台“发现缺水 → 取水壶 → 浇水 → 扶手椅休息”已通过合同测试。

### C9.2 `[ACTIVE]` 微行为层

已有按角色配置、带冷却且无对白刷屏的注视/思考基线；后续增加呼吸、眨眼、重心变化、环顾、转身、整理衣物、看附近物体、听见说话时转头，以及坐下后的姿势调整。

### C9.3 `[ACTIVE baseline]` 行为过渡和承诺

已有目标朝向、活动资源锁、完成后安静期、玩家抢占、暂停任务保留、交互后条件/资源复查和原任务恢复；后续增加短暂停顿、起身、执行结果检查和更细的重新规划。

### C9.4 `[DONE baseline]` 角色个性差异

咕咕嘎嘎与诀已有独立活动偏好、微行为配置、需求状态和结果记忆；后续补地点偏好、作息、动作速度、社交阈值和表达方式。

### C9.5a `[DONE embodied-reaction baseline]` 玩家扰动物体的角色反应

玩家踢动靠枕后，物理观察器发布带实时坐标的世界事件；最近的空闲角色形成独立
情景记忆，转头并表现惊讶，然后执行“说话 → 走近 → 拿起 → 放下”的白名单动作
链。演出模式会抑制这条自由生活旁路，避免破坏剧本编排。

### C9.5b `[ACTIVE portable-tool baseline]` 完整浇水样板

寻找水壶、占用、走近、对齐、手部 IK 抓取、携带、倒水动画、水流粒子/音效、植物反馈和水壶归位。

- `[DONE baseline]` 水壶以可携带刚体进入 Manifest/Registry；GOAP 在当前房间
  存在水壶时生成“走近水壶 → 拿起 → 走近盆栽 → 浇水 → 放下”的五步链，
  植物含水量和可见状态真实更新。
- `[DONE presentation v0.8.15]` 可携带工具通过通用 `play_tool_use` 协议委派
  模型自身表现；浇水壶会平滑倾倒、从壶嘴发射水滴粒子并播放程序化水声，结束
  后恢复持有姿态，无需由 ActionExecutor 识别具体资源路径。
- `[NEXT]` 水壶/盆栽占用联锁、身体与壶嘴精确对齐、手部 IK、水量状态、洒水
  失败反馈和准确归位。

### C9.6 `[NEXT]` 共同活动协议

邀请、接受/拒绝、等待、并行走位、座位预订、共同看电视/读书/照顾植物、短对话和自然结束。

### C9.7 `[LATER]` 生活节奏控制

避免频繁走动和台词刷屏，引入安静时段、活动时长、注意力、疲劳、恢复原任务和可被玩家打断的优先级。

### C9.8 `[LATER]` 生活感诊断面板

开发模式显示候选活动、评分原因、当前目标、行动步骤、占用资源和失败原因；正式模式隐藏系统日志。

## 实现原则

- Utility AI 决定"现在更想做什么"，GOAP/HTN 决定"如何安全完成"
- LLM 负责高层意图、自然语言、复杂社交判断和长期反思，不负责碰撞关键行为
- 即时物理反应由本地事件/Utility 层在一帧内启动，LLM 可在后续异步丰富语言与
  长期计划，不能成为“看到物体被碰动”的延迟瓶颈
- 动作匹配模型只能改善动作选择，不能替代 interaction point、物体占用、IK 和碰撞
- 随机微行为必须受姿势、附近物体、当前关注对象和冷却约束，不能成为无意义抖动

## 五分钟生活感验收

> 玩家不输入指令，连续观察五分钟，两个角色仍能表现出互不冲突、具有个性差异、
> 有开始/过渡/结束的连续生活；玩家中途插话时，目标角色会停下或安全收尾、转向
> 玩家并回应，随后根据上下文恢复原任务或重新选择目标。

### 量化检查

- 五分钟内至少出现 3 类不同活动，且同一活动不会无意义连续重复
- 至少一次由环境/需求触发的物体交互和一次角色间共同活动
- 角色不会隔空交互、抢占同一座位/物体、穿过主要家具或在路径失败后假装成功
- 玩家消息到角色产生可见注意力反馈的延迟低于 500 ms；完整语言回复可异步到达
- 每个重要行为能够在诊断面板解释选择原因和执行结果
