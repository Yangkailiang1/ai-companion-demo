# S1. 场景美术、UI 与视听表现

> 所属分支：S. 场景与世界
> 节点编号：S1
> 状态：`[ACTIVE]`
> 依赖：无（基础视觉层）
> 最后更新：2026-07-29 | 基线程：v0.8.11

## 当前状态

已有暖色客厅、PBR 家具、环绕相机、温馨 UI、输入焦点和基础环境背景。

## 规划节点

### S1.1 `[ACTIVE compact-history baseline]` 聊天 UI 完善

聊天消息气泡化、折叠聊天记录、角色头像、目标角色选择器。

- `[DONE]` 完整记录默认折叠为输入框上方的小按钮，仅保留最近 10 条；展开面板
  缩小并远离屏幕中心，第一人称输入时不再遮挡主要视野。
- `[NEXT]` 角色头像、目标角色选择器、单条临时字幕与未读状态动画。

### S1.2 `[ACTIVE lighting baseline]` 场景细节完善

完善家具比例、接触阴影、墙体细节、窗景、昼夜灯光和环境音。

- `[DONE baseline]` 五个参数化房间在 Manifest 中分别声明 key/fill/accent
  色温、强度、位置与范围；运行时只启用玩家当前房间的三灯光组，避免拼接住宅
  的多个无限方向光叠加。
- `[DONE baseline]` 主环境压低泛白环境光与曝光，启用 SSAO 接触阴影；方向主光
  使用柔化角度和半透明阴影，浅色角色衣服不再依赖整体泛黄来获得暖感。
- `[DONE character separation]` 角色采用统一 `anime_toon_v1` 阶梯光照和
  缩放校正轮廓；场景与家具继续使用暖色 PBR，形成“二次元角色生活在有质感的
  室内空间”而非全画面卡通化。透明头发/衣服贴图参与描边裁切。
- `[DONE cinematic lighting]` 演出观察镜头启用相机轴向柔和暖色补光并临时
  隐藏世界姓名牌，结束后完整恢复；自由模式和第一人称不受影响。
- `[NEXT]` 昼夜曲线、窗外天空/反射探针、灯具真实开关联动、墙面材质和环境音。

### S1.3 `[NEXT]` 响应式 UI

响应式 UI：窗口缩放、16:9/16:10、超宽屏和高 DPI。

### S1.4 `[LATER]` 设置与诊断面板

设置页、模型/音频/AI 状态页和开发者诊断面板。

### S1.5 `[LATER]` 摄影模式

摄影模式、景深、镜头预设和截图/录像。

## 验收标准

- 主要物体不悬空、不穿模
- 1280×720 至 2560×1440 可读
- UI 不抢占相机输入
- 场景在目标设备达到性能预算
