# 统一完成标准

> 所属文档：AI Living Town 开发规划树
> 最后更新：2026-07-24 | 基线程：v0.7

任何规划节点标记为 `[DONE]` 前，至少满足以下全部条件：

## 验收标准

1. **有可验证的结果**
   - 有用户可见或 Runtime 可验证的结果

2. **有失败与降级路径**
   - 失败场景有明确的处理路径
   - 关键功能在依赖不可用时仍能降级运行

3. **安全与隐私**
   - 不在代码或仓库中写入私密 API Key
   - 不将用户数据、语音样本、聊天记录提交到仓库

4. **自动化测试**
   - 有 headless 合同测试
   - 视觉任务另有截图验收

5. **文档更新**
   - 更新相关协议、资产来源和开发文档
   - 在本规划树中更新对应节点的状态标签

6. **版本管理**
   - 关键版本形成独立 Git 提交

7. **扩展性验证**
   - 新角色、新场景和新物体不依赖修改核心认知代码才能接入
   - 证明了该功能可以通过标准接口扩展
