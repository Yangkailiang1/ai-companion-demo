# Q 版角色资产审计与接入规范

> 对应需求：C6（角色导入）、C8（角色美术）、O4（开源治理）
> 审计日期：2026-07-27

## 结论

原 `model/Q版/` 中除小企鹅外的角色包都是 MMD `.pmx` 模型，Godot 不能直接
作为标准角色资产导入；需要先在 Blender 中转换成 `.glb`，再做骨骼、材质、
表情和动作适配。小企鹅是 VRM/Blend，同样需要转换或插件支持。

2026-07-27 已完成全部 22 个压缩包的 Readme 审计：没有一个压缩包提供允许
随开源游戏再分发的明确授权。9 个明确禁止非 MMD 视频/视频以外用途；12 个
允许一定修改但禁止商业使用和二次配布；1 个 VRM 只有加载说明而没有完整授权。
这些文件已移动到 `model/Q版/_不可进入开源Godot项目/`，未删除。

按用户要求，`v0.8.5` 从第二类中选择 Chibi Castorice、卡提希娅和相里要做
本机非商业技术验证。转换后的 GLB 与角色 manifest 位于 Git 忽略的
`assets/local_characters/`，
不会提交、打包或随开源项目分发。该验证不改变原模型许可证，也不代表正式
开源角色资产已经解决。

项目侧已经完成 version-1 运行时角色 manifest 和动态适配器注册：转换后的
GLB 可以分别声明动作 clip、语义骨骼和表情 morph 映射，并自动进入 ECNU
剧情规划的 cast 白名单。当前缺口已经从“Runtime 不支持多模型”缩小为
“PMX 资产需要转换、逐角色检查和确认授权”。

## 当前盘点

| 分类 | 数量 | 当前处理 |
|---|---:|---|
| 明确禁止游戏或非视频用途 | 9 | 不转换、不接入 Godot 项目 |
| 仅限本地非商业且禁止再分发 | 12 | 只可作隔离的个人研究，禁止提交或打包 |
| 授权不完整待确认 | 1 | 取得作者/IP 方明确许可前禁止入库 |

卡提希娅、椿和釉瑚各有一份 SHA-256 完全相同的副本。为避免未经授权删除用户
素材，当前仍保留副本，并在隔离目录审计文件中标注。

## 标准角色包要求

正式可接入角色优先提供：

- `.glb` 或 `.gltf`；VRM 可通过离线工具转换；
- 人形骨骼的 T/A Pose 基准、正面方向和真实身高；
- 材质贴图、BlendShape/表情名称、可用动画清单；
- 明确许可证文件、作者与来源链接；
- 若允许二次分发，明确模型、贴图、动画是否采用同一许可证。

角色包进入项目后必须拥有稳定 `agent_id`，并在
`data/character_runtime_adapters.json` 分别声明动作、骨骼和表情通道映射。
剧情导演和认知系统只输出语义提示，不依赖某个模型的骨骼名称。

## 本机 PMX 验证流水线

1. 只处理许可证明确允许游戏使用、格式转换和目标发行方式的资产。
2. 在隔离的本机素材目录解压，不复制进 `assets/`。
3. 使用 Blender 的 MMD 导入工具加载 PMX，检查贴图路径与透明材质。
4. 应用比例和朝向，保留原始骨骼与 morph，导出单一 GLB。
5. 把 VMD 烘焙为骨骼 Action，并将 MMD Toon/SPA 材质重建为 Godot 材质。
6. 在 Godot 中检查蒙皮、法线、透明排序、静止姿态与根节点朝向。
7. 编写该角色的骨骼/动作/表情适配配置并跑角色接入验收。

当前流水线已验证三份 PMX 的网格和贴图，以及 272/652/495 根骨骼、
37/69/70 个 Morph 和日文 MMD 骨骼/表情别名；本地加载器在资产缺失时安全
跳过，不破坏公开构建。三名角色已同时通过点名路由、挥手、微笑、动态剧本
cast 和独立记忆验收。

适配配置以 `data/examples/chibi_character_manifest.example.json` 为模板。
运行时由 `character_runtime_binding.gd` 注册，不需要为每个 Q 版角色复制
StoryDirector、LLM、MemorySystem 或动作/表情路由器。

可使用仍在维护的 Blender MMD 工具项目：
[MMD-Blender/blender_mmd_tools](https://github.com/MMD-Blender/blender_mmd_tools)。
其 v4.x 官方兼容表覆盖 Blender 4.2–5.1；本机 Blender 5.0.1 应使用最新
v4.x，而不是旧 `powroupi` 分支。实际批量转换前仍需先用一个角色验证材质、
骨骼、morph 和 GLB 导出结果。

## 需要用户补充的正式素材

为了把“多 Q 版角色小剧场”真正做进可开源版本，请优先寻找至少 2–4 个：

- 可再分发的 Q 版 GLB/VRM 人形模型；
- 带标准 humanoid 骨骼；
- 至少包含眨眼、微笑、难过三种表情；
- 允许项目演示、修改和随仓库发布；
- 最好附带 idle、walk、wave、nod、sit 五个基础动画。

没有附加动画也可以接入，但需要走现有离线动作库的重定向流程。
